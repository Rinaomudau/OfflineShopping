# Makro Offline Shopping App

## About the Project

This is a simple shopping application inspired by Makro. The application allows users to browse products, view product details, add items to their shopping cart and manage their shopping.

The application is developed using .NET MAUI and follows the Model-View-ViewModel (MVVM) architecture.

## Features

- View available products.
- Browse product information.
- View product prices.
- Add products to the shopping cart.
- View shopping cart items.
- Calculate the total shopping amount.
- Offline functionality.

## Technologies Used

- C#
- .NET MAUI
- XAML
- SQLite
- MVVM Architecture

## Project Architecture

The application follows the MVVM pattern, which separates the application into three main parts:

Models: Contains the data and product information.

Views: Contains the XAML user interface.

ViewModels: Handles the application logic and connects the Models to the Views.

## Installation and Running

1. Download or clone the project.
2. Open the solution file in Visual Studio.
3. Restore the required NuGet packages.
4. Build the project.
5. Run the application using an available emulator or device.

## Purpose

The purpose of this project is to demonstrate the development of a shopping application using .NET MAUI while applying the MVVM architecture and offline data management.
